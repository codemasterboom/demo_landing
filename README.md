# Bang & Olufsen (B&O) audio hardware and smart home devices shop ( Design example )

This project show example of home page for some shop, where sale audio hardware and smart home devices.

# Live demo

Expirience the live website: [Store Demo](  https://codemasterboom.github.io/demo_landing/) 

Template based on design from [Figma model](https://www.figma.com/file/DtkQmQ797hk0nI4KfMi2Uq/BOSE-New-Version?type=design&node-id=6817-212&t=ZTV6Gl8NzaWkJ4FK-0)

Implemented with using parcel, to compile scss.

# Using project

To setup project localy:
1. Clone repository:
   ```
   https://github.com/codemasterboom/demo_landing.git
   cd demo_landing
   ```
3. Install dependencies:
   ```
   npm install
   ```
5. Run the project locally:
   ```
   npm start
   ```
